Household Calendar

A simple, shared view of upcoming appointments on a household tablet.

Household Calendar is operated by Donald Ludemann for personal household use. It combines the owner's primary Google Calendar, calendar requests emailed by approved household senders, and a maintained public U.S. holiday calendar.

How it works

A program on the owner's Linux computer updates the display once each day. The display offers today, tomorrow, this week, next week, this month, and next month views. It is served on the household network.

Google account access

The owner authorizes read-only Google Calendar access and separate read-only Gmail access. The program reads the primary calendar and searches for messages addressed to a designated calendar alias. Sender and recipient checks are applied before interpreting submissions. It does not send email or modify Google Calendar events.

Private display, public explanation

This website provides information about the project. It does not provide access to the household calendar, appointments, mailbox, or account credentials, and does not offer public account registration.
